# DWIHN AI Learning Curriculum

<p class="course-lede">A practical learning path for using AI with good judgment, verified information, and appropriate safeguards. Each module connects plain-language concepts to realistic workplace decisions.</p>

<img class="course-cover" src="/images/responsible-ai-training.png" alt="A diverse workplace team learning about analytics, reviewed documents, privacy, and communication workflows." />

<p class="image-caption">The course treats AI as one step inside a human-owned workflow, never as the final decision-maker.</p>

::: warning Training data rule
Use fictional names, records, transcripts, and datasets throughout training. DWIHN must approve any different practice environment before delivery.
:::

## Continuing case

Every module contributes to the **Community Access Improvement** case. In this fictional scenario, a behavioral-health access program sees more missed appointments, longer call queues, and uneven service completion across three invented service areas.

Learners will decide where AI can help, protect the fictional information, create prompts, inspect dashboards, correct a call summary, assess evidence, report concerns, and present a reviewed recommendation.
